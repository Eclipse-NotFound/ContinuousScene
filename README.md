# ContinuousScene：连续大场景 0.6.0

0.6候选正在完成回归，正式安装仍为0.5。完整修复依据、实测与失败记录见[本轮记录](knowledge/experiments/native-v06-20261015.md)，实现见[运行设计](design/runtime.md)。

## 使用

安装后保存并正常重启根目录1.02游戏。在模组设置的**连续大场景**页开启**以连续大场景载入原版地图**，再从原版任务入口出发。默认关闭、自动保存，下一次生成地图或读档生效，当前实例保持原有模式。基地、后室与挑战保留原版入口。

普通返回保留地图和灯具损坏；重新开始任务按原版规则刷新。原版随机任务读档回基地，重新出发才重新生成。信息页**大场景 · 工厂测试**仅为固定12房夹具，进入后按钮变为返回基地，重新出发重置夹具；它不代替原版任务入口。旅行仍尊重剧情、伤势和负重限制。

## 本轮改动

原版生成的标准48×25主层房间合并到一个Location（运行场景），镜头、敌人和弹体连续运行。全场逻辑与画面在进入时准备并常驻，镜头外仅隐藏显示对象。工厂192×75格、7680×3000像素，240个320px画面块只组织绘图，没有玩法边界。

0.6按区域一次绘制再分发小块，清理遮罩临时显示树，提前释放旧墙面覆盖层；“光与暗”在首次绘图前完成灯具转换，免去额外整图重绘。原版及LAD光照图恢复平滑缩放。保留LAD0.2氛围、闪烁、暗区与维修，WB改为等价的邻域计数及保护查询缓存，RV沿用v0.30.5-scene字节。

保留0.5的地图尺寸/定位、三档缩放、隔墙操作复核、区域色调/水/底墙和局部弹痕。原版念力能力例外保留。没有关闭效果、删除敌人或缩小视野。

同中间宿主对照，LAD0.2基线进图29.235秒、开火帧中位/P95为63/84ms，兼容候选为20.373秒、50/69ms；同期普通房43/70ms。随机内容不同，不能视为固定种子严格因果比较。最终实测与内存见报告，仍不能承诺稳定30帧。

## 开发与验证

构建源码锚点为根目录pfe_before_ContinuousScene_20261014-181702.swf（C631…C64867），合并已发布Map1宿主BEBEEA8B…4011F。Grafon整类重编，另移植17个方法，4652个无关方法/初始化保持，保留Map1 Land布局。不要重复给已安装宿主套补丁。

在游戏根目录运行build/build.ps1并指定上述-BaseHost；test-mods.ps1 -AllMods复制正式依赖，compat-build.ps1生成RV/WB候选。LAD从其已授权源码构建后把build/out候选复制至CS隔离runtime对应release。刷新清单用test-mods.ps1 -AllMods -Prepared，定向更新依赖用-RefreshModules，避免覆盖候选。

build/test.ps1的五套检查分别为：
- -Factory -NativeMap：原版任务、返回/重置、后室、读档与地图UI。
- -Factory -Experience：地图、缩放、交互、区域光照、电源与弹痕像素。
- -Factory：固定工厂、跨房战斗与保存；随后运行build/verify_factory.py核对内容/像素。
- 无上述模式：完整走廊回归，正式验收不能用-Quick代替。
- -Factory -Perf -Cull：真实帧间隔、实际开枪与局部刷新。

使用-HighQoS固定自有进程策略、-EvidenceName保留独立证据，顺序运行且不与构建或其他测试争用性能。测试只用独立AIR身份和存储，不接触正式存档；需要写自身隔离APPDATA权限。弹痕像素探针结束后直接退出，不继续存档。另需WB三套检查和LAD混装/冷启动保存检查。

RV/WB冻结源为0735491e49d0d286ea8847017ae2fb64067a3c71、f32e4a99643ccc901dc4f8e8caac29a6cde441b4，生成于CS build/generated，不发布其他任务WIP。Profile仅诊断用。ProbeOnly仅编探针，DriverOnly编入口及探针。共享工具在Sandevistan/build/tools，只读使用。

[Start-Scene.cmd](Start-Scene.cmd)仍是独立稀疏走廊，每次新开测试游戏，不是原版工厂入口。地图编辑继续暂缓。

## 限制与回退

完整剧情、全部机关/地图、联机、更大地图和长时破坏尚未全面验收。合并限标准主层；512×256格是输入保护上限，已测192×75工厂及192×60走廊。无远处实体休眠或按需读盘。历史实验见0.5及更早报告，不能移用为当前版本通过。

0.6门禁build/upgrade-v06.ps1核对五套主回归、WB/LAD兼容、精确产物指纹和正式基线，独立备份后仅替换宿主、CS、WB、LAD。RV、工厂XML、清单、氛围配置和其他模组保留。安装后另用正式路径和独立AIR身份做启动验证，失败回退。

0.6尚未安装，现有回执state/deployment-v05.json。安装后以state/deployment-v06.json及upgrade-v06.ps1 -Action Rollback为准；不要用历史整体备份覆盖其他模组后续发布。安装或回退都需正常重启。
