## 使用

保存并正常重启根目录 1.02 游戏。在模组设置的 **连续大场景** 页开启 **以连续大场景载入原版地图**，再从原版任务入口出发。默认关闭、自动保存，下一次生成地图或读档生效，当前实例保持原有模式。基地、后室与挑战保留原版入口。

普通返回保留地图和灯具损坏；重新开始任务按原版规则刷新。原版随机任务读档回基地，重新出发才重新生成。信息页 **大场景 · 工厂测试** 是固定 12 房测试地图，进入后按钮变为返回基地，重新出发重置测试图。旅行仍尊重剧情、伤势和负重限制。

## 运行方式与本轮改动

原版生成的标准 48×25 主层房间合并为一个 Location（运行场景）。全图敌人、物品、碰撞在进入前生成并常驻；镜头、敌人和弹体连续运行。按用户本轮明确选择，画面先准备实际视野，再提前分批绘制周围区域，已绘制区域保留到地图重置。320px 画面块只组织绘图，没有玩法边界。

延续0.7的出生位置首屏准备和移动方向预绘，缩放、震动与跳转仍同步补足视野。0.8的后续预绘保留相机边框状态；独有门/物品显示和移动机关端点统一平移，每原房奖励池保留。远处未参战敌人暂缓，附近、追击、受伤、持续效果及弹体附近保持运行；完整对象和碰撞数组保留，子弹不暂停。WallBlend 0.5.8-scene 跳过画面块裁剪区外的无效计算，采样缓冲和可见像素保留。

保留地图尺寸/定位、三档缩放、隔墙操作复核、区域色调/水/底墙、局部弹痕、地图刷新和设置开关。原版念力能力例外保留。本轮采用已发布 RV 0.32.3 与 LAD 0.3.1，没有改变它们的设置。

## 验证与限制

三次真实随机工厂进图从 beginMission 到转场结束、恢复操作计时，无其他 AIR 争用；各次全场生成 183/156/166 单位，初始绘制 24 块。不是固定种子的单变量实验，也不保证所有地图或机器都在 5 秒内。

当前首屏24块四层9,830,400像素与完整区域绘制精确一致；600帧位置驱动移动和缩放无缺块、无同步补绘。原版入口/刷新/读档/地图51项、工厂34项及内容像素10项、体验113项、调度奖励机关27项通过；本轮两种墙面样式24项、6组各112张可见图逐像素相同。旧版470项材质/破坏检查属于历史证据。

最终无争用大图待机帧耗时上中位50/59ms、步枪65ms、加特林74ms；普通房间参照41/44、46、54ms。两组枪均真实开火40/119发，但随机内容不同。持续卡顿尚未完全解决，仍未达到普通房间流畅度。原生生成偶发#1010在旧正式0.7关闭合并也复现，内部根因尚未修复。完整剧情、全部机关、联机、更大地图和长时破坏未全面验收；512×256仅输入上限，主要实测192×75工厂。

## 开发与复现

本轮以正式宿主2A466248为合并基线，仅重编Grafon并定向移植六个原生方法；4665个无关方法/初始化、1015类布局与原常量池前缀保持。最终产物和完整指纹在build/candidate-v08-final/，来源与字节码审计见报告。不要使用旧整包构建或备份覆盖后续宿主。

build/candidate-v08-build.ps1仅复现本轮冻结2A基线，不能自动升级任意新宿主。重新编译可能改变指纹，须重验。build.ps1 -ProbeOnly只编探针，-DriverOnly编入口及探针；不要运行旧整包合并。test-mods.ps1 -AllMods -Prepared刷新清单，-RefreshModules定向同步正式依赖。TDFC和WB的HEAD含未发布工作，本轮从准确冻结发布源生成，不能直接构建HEAD覆盖。

测试串行运行，独立 AIR 身份/目录，不访问真实存档：

- test.ps1 -Factory -Loading -LoadNative -EntryOnly -Progressive：真实原版随机工厂加载，非诊断性能测量。
- test.ps1 -Factory -Loading -LoadNative -Progressive -DiagnosticsOnly：首屏像素对照及 600 帧移动/缩放，不作速度验收。
- test.ps1 -Factory -NativeMap -Progressive：实际原版任务、返回/刷新、后室、读档与地图 UI。
- test.ps1 -Factory，随后 verify_factory.py <EvidenceName>：完整预绘参照、跨房战斗与保存、原版内容/像素。
- test.ps1 -Factory -Experience：完整预绘参照、缩放、交互、区域光照、电源与弹痕。

各次指定新-EvidenceName，性能采样不能与其他AIR或重编译并行。WallBlend从f32e4a9冻结源加0.5.6配方和本轮裁剪生成；TDFC从fb73655加桥接生成，均不混入其他未部署候选。共享工具在Sandevistan/build/tools，只读使用。

[Start-Scene.cmd](Start-Scene.cmd) 仍是独立稀疏走廊，每次新开测试游戏；原版工厂请用游戏内任务入口。
