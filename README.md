# ContinuousScene：连续大场景 0.7.0

0.7 已于 2026-10-16 15:12 安装，正式路径启动 19 项通过。真实原版随机工厂入口的三次独立加载测量为 **4.486 / 4.392 / 4.382 秒**。安装及回退依据见 [回执](state/deployment-v07.json)，完整证据、失败尝试与测量边界见 [加载优化记录](knowledge/experiments/loading-v07-20261016.md)，实现见 [运行设计](design/runtime.md)。

## 使用

保存并正常重启根目录 1.02 游戏。在模组设置的 **连续大场景** 页开启 **以连续大场景载入原版地图**，再从原版任务入口出发。默认关闭、自动保存，下一次生成地图或读档生效，当前实例保持原有模式。基地、后室与挑战保留原版入口。

普通返回保留地图和灯具损坏；重新开始任务按原版规则刷新。原版随机任务读档回基地，重新出发才重新生成。信息页 **大场景 · 工厂测试** 是固定 12 房测试地图，进入后按钮变为返回基地，重新出发重置测试图。旅行仍尊重剧情、伤势和负重限制。

## 运行方式与本轮改动

原版生成的标准 48×25 主层房间合并为一个 Location（运行场景）。全图敌人、物品、碰撞在进入前生成并常驻；镜头、敌人和弹体连续运行。按用户本轮明确选择，画面先准备实际视野，再提前分批绘制周围区域，已绘制区域保留到地图重置。320px 画面块只组织绘图，没有玩法边界。

0.7 在原版出生位置和镜头确定后批量准备首屏，避免重复绘制旧镜头位置；按移动方向提前准备周边块，缩放、震动与跳转仍同步补足实际视野。保留原生矢量遮罩和滤镜，只缩小材质填充中的透明外边界。WallBlend 0.5.6-scene 缓存确定性的接缝计算，跳过当前模式未使用的色调准备。原版转场的生成、控制、点击门槛与 HUD 恢复步骤保留，缩短渐隐结束后的空等。

保留之前的地图尺寸/定位、三档缩放、隔墙操作复核、区域色调/水/底墙、局部弹痕、地图刷新和设置开关。原版念力能力例外保留。本轮采用已发布 RV 0.31.1 与 LAD 0.3.1，没有改变它们的设置。

## 验证与限制

三次真实随机工厂进图从 beginMission 到转场结束、恢复操作计时，无其他 AIR 争用；各次全场生成 184/197/176 单位，初始绘制 24 块。它们不是固定种子的单变量实验，也不是全部地图或机器都保证 5 秒。功能诊断另有一次 5.724 秒观察，已保留。

最终首屏 24 块、四层共 9,830,400 像素与完整区域绘制精确一致；600 帧位置驱动移动和缩放无缺块、无同步补绘、无移动淘汰。原版任务、后室、刷新/读档、地图 UI 通过 51 项检查；工厂 34 项、内容像素 10 项、体验回归 113 项；WallBlend 历史模式、4120 材质组合和破坏效果共 470 项全部通过。

游玩中仍存在长帧，单块预绘诊断最大 91ms；本轮不宣称已恢复原版帧率或已彻底解决开火卡顿。诊断帧统计包含截图和全图对照后的恢复，不能当作干净的性能采样。完整剧情、全部地图/机关、联机、更大地图和长时破坏尚未全面验收。512×256 格是输入保护上限，主要实测 192×75 工厂；编辑器继续暂缓。

## 开发与复现

本轮以包含 PermanentInjury 的正式宿主 08A96759 为合并基线，仅重编 Grafon；4671 个无关方法/初始化、1015 类布局与原常量池前缀保持。最终产物和完整指纹在 build/candidate-v07-final/，来源与字节码审计见报告。不要使用旧整包构建或备份覆盖后续宿主。

build/candidate-v07-build.ps1 是本轮冻结基线的复现入口，要求已有 build/cache/v07-baseline/，重新编译可能改变产物指纹，必须重验并更新门禁；它不是自动升级任意新宿主的脚本。prepare.py 使用原 C631 参考导出源码；--sources-only 必须放在基础文件路径之后。build.ps1 -ProbeOnly 只编探针；-DriverOnly 编入口及探针。test-mods.ps1 -AllMods -Prepared 刷新清单，-RefreshModules 定向同步正式依赖，避免覆盖候选。

测试串行运行，独立 AIR 身份/目录，不访问真实存档：

- test.ps1 -Factory -Loading -LoadNative -EntryOnly -Progressive：真实原版随机工厂加载，非诊断性能测量。
- test.ps1 -Factory -Loading -LoadNative -Progressive -DiagnosticsOnly：首屏像素对照及 600 帧移动/缩放，不作速度验收。
- test.ps1 -Factory -NativeMap -Progressive：实际原版任务、返回/刷新、后室、读档与地图 UI。
- test.ps1 -Factory，随后 verify_factory.py <EvidenceName>：完整预绘参照、跨房战斗与保存、原版内容/像素。
- test.ps1 -Factory -Experience：完整预绘参照、缩放、交互、区域光照、电源与弹痕。

各次指定独立 -EvidenceName，性能采样不能与其他 AIR 或重编译并行。WallBlend 从 f32e4a9 冻结源生成，0.5.6-scene 与 RConnect 的未部署 A40 比较缓存候选不同；不写其开发源码。共享工具在 Sandevistan/build/tools，只读使用。

[Start-Scene.cmd](Start-Scene.cmd) 仍是独立稀疏走廊，每次新开测试游戏；原版工厂请用游戏内任务入口。

## 部署与回退

build/upgrade-v07.ps1 验证最终输入指纹、三轮进图、原版任务/画面/玩法和 WB 三套检查，独立备份后仅替换宿主、CS、WB。RV、LAD、清单、工厂 XML、配置和其他模组保持原有正式字节。正式路径另用独立 AIR 身份启动复核，结果写入 [deployment-v07.json](state/deployment-v07.json)。

回退用 build/upgrade-v07.ps1 -Action Rollback；仅接受三个目标仍为本轮版本时还原对应备份，拒绝覆盖后来发布。不要使用旧 0.6 或更早的整体备份。安装与回退都需正常重启游戏。
