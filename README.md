# ContinuousScene：连续大场景 0.2.0

当前阶段只做大场景运行，地图编辑暂缓。样片使用原版素材与战斗系统，测试地图为 **192×60 格，即 7680×2400 像素**。场景内没有换房线，玩家、敌人和弹体共用同一个坐标空间。

## 游戏内入口

本版已安装到根目录 1.02 游戏。保存并正常重启游戏后，打开哔哔小马的 **信息页**，点击顶部的 **大场景 · 连续探索**；进入后同一按钮变成 **大场景 · 返回基地**。入口沿用原版旅行限制，受伤、负重或剧情条件不允许旅行时不会强制传送。

正式场景沿用当前角色，不自动创建游戏、拉怪或改写测试存档。它是运行测试地图，还不是完整关卡。RealisticVision 与 WallBlend 的显示效果已适配，配置与玩家已有选择保持。

## 独立试玩

双击本目录的 **[Start-Scene.cmd](Start-Scene.cmd)**。约 20 秒后进入独立测试窗口；每次启动创建一局新的测试游戏。A/D 移动、空格跳跃、鼠标左键攻击、R 换弹、I 打开物品栏，沿用原版操作。长走廊中放了三只原版鼠怪，可测试移动和战斗。关闭游戏窗口退出。

这是简化的运行测试场景：有长走廊、上层平台、竖向通道和混凝土破坏目标。独立试玩额外放置三只鼠怪；正式游戏入口不会自动放怪。手动入口与自动测试共用独立应用身份，同一时间只开一个。

隔离产物位于 `build/runtime/`，测试存储为 `%APPDATA%/pfe-modsettings-continuous-scene/Local Store/`。自动验证不读写玩家正式存档；当前玩家游戏未被关闭。生产模组与测试驱动分离，测试驱动没有安装到正式加载清单。

## 现在做到哪里

一个扩大的 `Location`（原版的房间运行对象）承载整个场景；显示按 **320×320 像素**切成缓存块。镜头附近提前准备画面，远处画面释放；实体与碰撞数据继续存在，跨绘图块不切地图，不转移或重生单位。原版存档另保存稀疏地形变化和破坏痕迹，读旧档与新档不会互相串状态。

构建改动集中在场景尺寸、镜头、地形绘制与保存挂接。原版敌人 AI、子弹命中和碰撞方法继续执行。入口/兼容/存档验证见 [0.2 验证与安装记录](knowledge/experiments/integration-v02-20261014.md)，实现边界见 [运行设计](design/runtime.md)。

当前限制：

- 只实测上述尺寸、少量敌人与 1280×800 窗口。当前已启用模组组合通过测试；联机、更大地图、密集战斗与长时间游玩未验收。
- 全模组长距离行走帧间隔中位数 56ms、p95 85ms，仍未稳定达到原版 30 帧；首次进入、瞬移或集中重绘仍会停顿。
- 全场景格子和实体仍在内存中，当前分块负责绘图缓存；尚未做远处实体休眠或场景数据按需读盘。
- 大场景固定原倍率，暂时禁用原版“缩放到整间房”模式。
- 存读档沿用原版检查点语义；本版补齐大场景地形破坏与弹痕的跨读档保留，并验证新旧存档交替加载。
- SATS 画面覆盖已验证；完整战术操作、水体变化、动态门、剧情、地图界面、所有武器和不同窗口尺寸未逐项验证。
- 地图编辑器暂缓。`build/runtime/scene.xml` 是生成的测试夹具，下次完整构建会重写。

## 构建与自动验证

在游戏根目录的 PowerShell 执行：

```powershell
& './mods/ContinuousScene/build/build.ps1' -BaseHost './pfe_before_ContinuousScene_20261014-181702.swf'
& './mods/ContinuousScene/build/test-mods.ps1' -AllMods
& './mods/ContinuousScene/build/compat-build.ps1'
& './mods/ContinuousScene/build/test.ps1' -EvidenceName 'my-run' -TimeoutSeconds 380
```

完整测试自动进行横向长距离往返、跨边界追击与射击、纵向落地、地形破坏与缓存重载、普通房间往返、独立存档保存读取，完成后关闭自己的实例。使用 `-Quick` 跳过长距离往返，只检查战斗与场景生命周期。`-EvidenceName` 取新的英文短名，避免覆盖旧证据。

只改外部测试驱动用 `build/build.ps1 -ProbeOnly`；只编生产模组与驱动用 `-DriverOnly`。完整构建必须指定未经本补丁修改的已验证备份；安装后直接拿根 pfe 重复打补丁会被指纹保护拒绝。FFDec 重编译绘图类，其余改动通过官方 `-replace` 替换四个方法，最后核对 4665 个无关具名方法和初始化方法。MainFE 清单加载器保持原字节。

RV 兼容构建固定从已安装版本对应的 `0735491` 源码取源，再应用大场景补丁，不发布其工作区中另一个任务尚未安装的 authority 接口。WallBlend 使用已获授权的当前兼容源码。不要在兼容构建之后重新复制旧模组覆盖候选。

## 安装与回退

当前安装回执为 `build/install-receipt.json`；宿主备份 `pfe_before_ContinuousScene_20261014-181702.swf`，原清单与 RV/WB 备份位于 `build/backups/install-20261014-181702/`。从游戏根运行 `& './mods/ContinuousScene/build/rollback.ps1'` 可核对指纹后整体恢复本次安装，再正常重启游戏。回退前若正式存档停在大场景，应先返回基地并保存。

未来部署须重新通过完整候选、原版墙面、视野和安装后原生启动检查。`build/install.ps1` 是本次已知旧版本的安装器，不是无条件覆盖升级器。

当前工具位于 `mods/Sandevistan/build/tools/`，仅作为共享只读工具链使用；Java 与 Python 路径可通过构建脚本参数覆盖。构建输出和游戏资源副本不入 Git。当前版本仅匹配 2026-10-14 核对的 1.02 宿主，Steam 更新后须重新调查和适配。
