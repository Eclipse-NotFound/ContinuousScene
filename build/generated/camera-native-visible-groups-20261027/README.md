# 改正黑区路线后的可见物件分组缓存

前一 near-groups 虽像素/计时/恢复通过，实际PNG显示镜头位于玩家楼层下方，几乎全黑；因此不能将前四个active-quiet原版/大场景数字当正常场景性能基准，也不能据near-groups判定真正屏内物件缓存收益。

本变体不改候选算法，保持SceneNativeGroupCache逐字节相同。唯一路线中心改为实际初始玩家X/Y，仍原生camRun+calc、相同横纵偏移、模拟正常、无测量中瞬移。每视角保存PNG并检查避开主要HUD后的画面至少15%像素亮度>20；最终核1920样本角色位置始终在可见范围。这个像素门槛只排除明显黑区，仍须查看PNG，不能自动代替视觉验收。

依旧无敌人诊断，不是自然跳跃或战斗验收；完整1920区间与原候选图像/顺序/恢复门禁，526正式/13运行库/87源冻结。前一黑区实测保留原结果但限制用途，不重新标为性能成功。无部署。
