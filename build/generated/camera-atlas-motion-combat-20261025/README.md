# 原尺寸合图的真实战斗ABBA

当前仅候选验证，未部署，不预先认定战斗提速或视觉兼容。

`run.py`从B7ED收据/39A的85份冻结源出发，仅改变Main与SceneRasterPresentation。Main保留四段300帧的原生冲刺、加速/击退/耐力、玩家原生步枪及六名原生LMG敌人；全部1200连续间隔和首次构建/切换保留。图形变体与暂停试验的原尺寸motion-only相同，仅增加不改变状态的snapshot以核对清理。

每帧记录enabled/presented及前一帧的对应状态、真实镜头与世界显示坐标/缩放/震动、累计复制与重建。计时位置不动：每个间隔包含上一帧呈现和本帧更新；段界不剔除，不能将分组均值描述为无混杂的逐帧成本。A分支仍执行禁用/clear，这是同探针A/B，后续实际生产包还需独立验收。

源变换逐字反向恢复，拒绝非准确源。Main补足原探针缺少的atlas清理，在最终计时关闭后释放，并校验无挂接层、活位图、隐藏原图或姿态残留。runner复用已审查的编译实现与连续计时/负载核验；未复用暂停世界驱动或改变帧率。原生位移为零强制setPos、六敌存活/持枪/实射、真实冲刺速度、并发弹体等仍须通过。

测试按game登记、唯一AIR ID/私有桌面/独立存储，4GiB提交与2GiB物理余量预检、512MiB运行下限不变；不关玩家实例，不改正式SWF。

此轮保留真实震动/显示变换，只判断收益，不宣称其已符合RGB2像素要求。此前原尺寸暂停试验五视口通过，但旧0.8缩放与分数震动出现RGB96/71反证，不能仅凭用户接受RGB2就推广；生产前仍须验证变换范围、SATS、动态命中与跨缓存边界，以及必要RV/WB兼容。
