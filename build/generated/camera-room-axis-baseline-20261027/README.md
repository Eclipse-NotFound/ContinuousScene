# 同房间内部镜头原生对照

当前2048外窗的实际画布2032×1084，比原版房间1920×1000更大；该原版房间整间入镜，原生边界会固定镜头。不能把它的静止帧直接当作大场景连续镜头的同负载渲染基线。

本组仅诊断：使用同一当前安装和固定seed20261019，普通模式选择已验证房间(2,4)和原路线480/119；连续模式看同房间内部。实际画布1280×720，中心局部960/600，横向±120、纵向±48，使两个模式都真正连续移动，边缘不超出原房间。世界暂停、时间轴仍活跃；六战斗夹具准备保持，但绝不当真实无敌人/战斗游玩FPS。普通与大图的世界实体数量及其他远处内容不同，不能当完全相同负载。

每侧960帧静止/横/纵/组合正反序、五视口原生重复图精确、10截图释放、八个预绘计数不变、玩家/镜头/帧率/私有窗口恢复。比较实际镜头轨迹平移后相同、地图种子和匹配房间tile hash；记录当前RC和所有正式/运行输入。没有产品候选，不部署。
