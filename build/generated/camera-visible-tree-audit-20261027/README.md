# 可见镜头与完整显示树审计

只读诊断，未加入绘制优化。以真实角色初始位置为中心，1280×720、zoom1，模拟活跃，静/横/纵/斜正反960完整区间。每视角保存原生PNG、至少15%非黑像素、全程角色位于视野；分段时间逐帧守恒，帧间并非纯GPU时间。

在隔离夹具移除敌人之前清点完整原生显示树；移除后、计时前59帧再清点静态场景树。记录全部节点局部/Stage矩阵和包围盒、显式可见性/alpha链、缓存/滤镜/遮罩/滚动裁剪，以及共享BitmapData身份与实际尺寸。无stop/play、无显示属性写入、无像素存储分配；getBounds不等于实际可见像素，也不证明有多少绘制成本。最多20000节点、任何读取错误拒绝通过，不截断后当完整。

仍保留既有终结式无敌人夹具、独立桌面/存储、共享game登记和内存保护，正式文件不改。526正式/13运行库/87冻结源。目的是查超大缓存/滤镜或广域显示分支，不把未知工作直接称为瓶颈；读数须结合后续针对性对照。
