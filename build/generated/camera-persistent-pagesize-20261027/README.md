# 合图页尺寸对照

1280页持续合图的20×60实际横向战斗对照已有约13%平均收益，但仍远慢于30fps预算。本轮检查是否还有分页边界/位图数量的成本：同一原生镜头路线比较现有绘制、1280页、2560页。仍为活跃无敌人诊断，不能冒充真实战斗或自然跳跃。

新2560页每页8×8格，4页上限、16图、400MiB；1280页保留8页、32图、200MiB。准备时间与内存单列，不在产品中启用该内存策略。16状态Flash夹具扩展至12列，真实越过2560页边界；像素容许仍RGB≤2、alpha0、原生恢复完全相同。完整2880区间、静止额外开销、分方向与正反顺序都保留。

如果较大页没有稳定收益，结束此路线，不把高内存方案当默认升级。未部署。
