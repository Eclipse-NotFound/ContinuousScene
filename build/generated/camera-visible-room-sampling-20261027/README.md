# 可见内景中的静止与移动调用栈

在统一探索历史的3,3平台中，继续原生模拟及原有静/横/纵/组合路线；每窗仅最后五个镜头区间打开AIR已验证的采样接口。目标是区分镜头移动期间增加的原生绘制、排队帧脚本和可命名AS3工作，不能把这些受观察器干扰的间隔用作性能验收。

复用已核验combat-sampler-v3的受限采样实现，只调整窗口115–119、八窗、类名和边界描述。仍保留所有原始CPU时间、全局索引、完整栈及分类型时间诊断；新配方按CPU类自身的单调时间验证。旧v3混合流不单调的失败记录不修改。内部分配关闭，AS分配仍会记录；每窗100000记录上限，溢出使整轮诊断失败。采样暂停后才聚合，聚合成本保留，终结实例停止采样并清理回调。

只编译隔离测试程序，87源，正式宿主和模组不改。不调用Ghost、不触碰用户存储，继续4GiB提交/2GiB物理、共享登记及私有桌面保护。
