# 仅由原生帧循环更新镜头的诊断

既有quiet探针每帧在原生World.step之外再调一次Camera.calc；两版本同样受影响，但会放大大场景相机/预绘的绝对成本。此前分配采样已区分原生与额外调用，不能把去掉测试开销说成产品提速。

本配方保持150环境行为检查、原生世界模拟、同一内景/探索历史/五视角和960完整静横纵组合区间。准备和截图仍可同步调用calc；计时阶段在同一Stage的ENTER_FRAME优先级500只设置下一目标，让原生MainMenu/World在优先级0更新。观察器-1000逐次核目标、vx/vy、实际矩阵和可见区域。计时阶段任何helper calc立即失败。

先预备一帧原生目标，再记录960个完整间隔。窗口边界间隔保留，包含下一窗口的原生计算，不能叫独占绘制时间。计划961次（含种子帧和最后区间），捕获960次，终结时移除自己的监听器。未停原生模拟、未改玩家位置或宿主方法。仍是私有桌面120fps诊断，不代表自然跳跃/真实显示器帧率/战斗验收。

新旧测量路径不直接作产品性能比较；当前A796与F15候选必须复用本配方的同一编译探针。旧证据与失败保持。共享登记、唯一AIR存储、4GiB提交/2GiB物理保护以及精确输入指纹全部沿用；无正式部署。

可选--wait-ready-seconds（0–300）在申请测试登记之前短时等资源：每5秒只读内存与AIR状态，至少连续三次≥5GiB提交余量/2GiB物理且无AIR才接续，保存原始读数。超时保存未就绪回执，不构建、不建测试实例、不占测试登记。原构建前/启动前4GiB检查和运行中保护不变。此等待不代表其他非AIR后台负载已排除。
