# 保留效果外延的批量剔除＋一次整体区域绘制

前三轮证明：整树画512区域仍11.9ms；逐对象draw约697次/刷新严重倒退；短剖析中474个带阴影物件在几何区外但被保守保留。这里从region-refresh派生，恢复一次整体draw，只在这次同步draw期间隐藏确定不影响该区域的阴影物件，finally恢复。

资格仅已知中性、单位矩阵visObjs层的孩子；遍历舞台遮罩引用并排除其所属子树。递归合并几何与子节点效果外延，只支持单位平移/轴向反射及DropShadow、Glow、Blur、ColorMatrix，遇scrollRect/遮罩/3D/缩放/未知滤镜即保留原生。不猜原生裁剪Bitmap的行为。只有含DropShadow且保守外延完全不交512区域的根才临时隐藏。

效果外延调用[BitmapData.generateFilterRect](https://airsdk.dev/reference/actionscript/3.0/flash/display/BitmapData.html#generateFilterRect())，按文档实际分配与源范围同尺寸的临时BitmapData，避免inner滤镜按错误的一像素源裁剪。每层反射使用对称扩张，再留2像素余量。临时图立即释放并另有计数/峰值。此边界构造仍需运行时像素证明，不因API名称自称已正确。

13个候选区域各额外与未剔除的原生整树draw比较，要求完全相等（alpha/RGB都0差）；任何差异立即终止。每个GPU区间计入隐藏、恢复、单次整树绘制及上传；不留跨帧隐藏。不重建房间、不重设动画或图形。固定姿态的边界缓存不是动态失效跟踪，不能直接部署。

同8×120窗口/反序配对、全长帧保留。预计493区域刷新、13额外区域参照、8纹理、10持久/常规CPU图＋临时滤镜边界图，501上传、514copies（临时边界图不绘制）。原生自然往返、原生恢复、正式526/运行库13/源86及隔离登记沿原链。原有整图RGB2失败仍拒绝，本轮只验证局部剔除正确性和代价。
