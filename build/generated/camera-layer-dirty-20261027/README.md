# 活动时间轴分层缓存原型

将世界按原始层序分组：背景/底部物件、角色、前景、特效、明暗等。首次绘制每组并缓存；后续观察 MovieClip.currentFrame 变化，仅重画该组。地形已有位图继续由原生保持，缓存按实际透明边界裁切，镜头只改变显卡上的位置。不停止、重播或跳转任何原生动画。

这是新的动态成本原型：不同于每帧重画完整世界/512区域，也不同于逐物件数百次 draw。各组仍调用一次原生整根绘制，但只在该组变化时执行；同步临时隐藏其他直接层，finally恢复。不重新挂载原生对象。透明边界增长时在计时内重建缓存，旧资源释放。CPU和GPU各限制128MiB。

仍暂停游戏模拟，当前只追踪时间轴帧变化和相应子树重建；没有覆盖任意BitmapData像素写入、脚本变换、子弹、门、进出地图和RV。不能作为产品部署。GPU读回叠软件UI不是操作系统窗口截图。画质仍按RGB≤2/alpha0明确记录，通过运行不等于通过画质或实战。

相同实例与镜头路线，960连续区间，原生静止/移动、候选静止/移动及反序。所有长帧保留；仅变化的组重绘与上传、动画变化、图像/纹理释放都有计数。独立AIR ID/存储、私有桌面、共享game登记和4GiB提交内存门槛沿已有驱动。正式文件只读。

API依据：<https://airsdk.dev/reference/actionscript/3.0/flash/display/BitmapData.html#draw()>。原生draw对源对象自身的变换/颜色/混合有特殊语义，因此本候选在完整原生root内遮蔽其他层，再画root，不逐物件自建滤镜顺序。
