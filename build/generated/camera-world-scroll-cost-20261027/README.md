# 无缓存窗口滚动的代价诊断：不是画面验收

已知不缓存版本有一像素RGB差3，超过接受的2；缓存版本在有效原生对照后出现maxRGB92，
不继续缓存路线。为避免只在像素门槛前停住却不知道方向有无价值，本轮只测无缓存方式的
代价。**原RGB2部署/候选标准不变**：每视角记录accepted，任一超界则visualAccepted=false，
并保存该视角完整PNG；不把diagnosticPassed/raw.ok当作画面或产品通过。

原生固定完整路线准备及三次独立往返必须精确；候选alpha必须相同、恢复必须精确。
颜色超界记录在qualityFailures，允许继续这一诊断计时，供决定继续修精度还是放弃。
不会部署它，不以该诊断称达成用户目标。无敌人实玩、战斗、RV、SATS等仍需独立验收。

0/1/1/0四窗口480帧；5视角75捕获，原生预绘计数保持，无缓存分配请求。不改变旧失败，
不缓存版本仍有原生cam.calc之后复位世界位置的额外写入。所有原有隔离/清理/输入核验保留。
