# 失败绘制路线的单次对象耗时定位

region-items在第三窗口的111间隔后超时：GPU静止770.38ms，局部重绘756.32ms/次；每次查询2368个根、跳过1671、仍draw697次。不能把351条不完整记录当完整镜头对照，也不延长原失败测试。

本轮取消全部960帧率窗口，仅保留原有13像素/18自然往返与恢复检查。在第一次区域绘制时记录每个实际draw的类型、耗时、世界几何界、是否位于区域之外、滤镜/遮罩阻止剔除的原因、Bitmap源尺寸和混合方式。记录只是归因，尤其“几何界在区域外”不代表滤镜输出可以安全丢弃。

不改变失败路线的算法，不寻找更优帧率；只判断接下来究竟该减少Bitmap调用、缓存矢量，还是解决滤镜保守剔除。第一调用的CPU耗时不是稳定动画成本。原方案依旧拒绝，不部署。独立桌面、唯一AIR ID、共享登记、正式文件/构建输入冻结与清理沿原链。
