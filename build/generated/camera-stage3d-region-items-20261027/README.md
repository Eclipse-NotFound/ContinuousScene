# 按显示对象绘制局部区域的成本

512平方区域仍花11.888ms/次CPU绘制，移动30.738→26.067ms，只改善约15%。本轮保留相同区域/缓存/对照，改为按世界原层序逐个绘制对象，研究是否能跳过区域外的树与图形。

只拆开已知的空包装层visBack、visBack2、visFront与visObjs；要求本层无滤镜/遮罩/颜色/透明度/矩阵变换，且直接孩子无外置遮罩。其余层原样整体draw。对无滤镜、遮罩、scrollRect和3D变换的整棵对象子树，按当前getBounds加1像素边缘剔除区域外内容；有这些效果的子树保留原生绘制，不猜效果外延。遍历当前子节点与求界包含在每帧成本中，筛选与绘制单列计时。

滤镜资格只在首次遇到对象时分类并记忆，因为本轮仍固定所有动画/模拟；**不是动态追踪实现**。实际新生/销毁/帧脚本/属性变更需另行处理，不得直接接入产品。首个候选区域另保存一次原生整体draw的透明区域作像素对照。原生恢复、完整画面RGB2门槛不变；差异明确记录，成本实验可继续但不部署。

其余沿region-refresh：8×120全区间，13像素检查，18自然预备组，正式526/运行库13指纹、独立桌面、唯一AIR ID和共享登记；预计493局部更新、8纹理、10CPU图（含1张独立区域参照），copies502/上传501。没有改动正式游戏或模组。
