# 大视口可见图层成本诊断

1920×1080、zoom1，角色初始位置居中，原生世界循环保持。仅隔离夹具移除敌人；不是实战，也不是用户机器真实显示帧率验收。八种条件：完整画面，分别暂时隐藏原生光照、地形、物体装饰、角色层、远景、原生HUD、整个world。保留其他层和原生逻辑，用于缩小镜头移动成本的来源，绝非产品优化。

静止/横/纵/组合移动，每个控制与相邻完整画面配对、正反顺序各一次。112×60=6720连续间隔，计入切换及所有长帧；每对坐标必须精确相等。EXIT_FRAME复核14个目标的可见性和父节点，以防被游戏提前重开。完整图像五视角保存且至少15%非黑；每项隐藏后恢复都需RGBA完全相同。隐藏条件故意改变画面，不适用候选RGB容差，不部署。

共享game登记、私有桌面、唯一AIR ID/存储、4GiB提交/2GiB物理预检及526正式/13运行库输入闭包沿现有runner。运行过配方冻结。耗时区间不是纯GPU，隐藏对象可能影响回调，先看native band与总间隔再解释。
