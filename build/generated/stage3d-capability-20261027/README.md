# 独立 Stage3D 能力验证

仅回答当前 AIR 运行库在私有桌面是否能创建 Context3D，以及清屏、像素读回与资源清理是否正常。独立 256×256 应用，无游戏/模组/存档加载，不发鼠标键盘输入，不联网。

- 请求 auto / baseline，保留 driverInfo 原文；硬件判断仅是运行库报告。
- 清屏颜色 (0.25,0.5,0.75,1)，验证全部 65536 像素：RGB 最大误差 1/255、alpha 完全一致。
- 10 秒内部超时、30 秒外部超时；仅清理本次持有原始句柄的自有进程。
- 共享 game 登记、无其他 AIR、可用提交内存 4GiB / 物理 2GiB、独立 AIR ID/存储、私有桌面；原有正式文件与运行库前后指纹比较。
- 这是能力检查，不是游戏帧率测试；Stage3D 位于原生显示树底部，单独读回不能验证混合显示、前景遮挡、光影、像素一致或用户桌面效果。
- 无性能收益、无生产验收、无部署。后续只有硬件能力成立才考虑受守卫的背景层原型。
