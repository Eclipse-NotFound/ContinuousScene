# 活动角色分项缓存（隔离候选）

目标是让镜头平移只移动纹理四边形。原生单 Bitmap 的简单链在颜色中性、无滤镜/遮罩/自有 graphics、整像素单位变换时直接上传其现有 BitmapData；每次更新重新上传，不凭对象身份假定像素不变。其他角色只在已观测的时间轴或根状态变化时生成小图。保留层序以及根 normal/screen/add 混合，未改动画播放。

继承 layer-region 的冻结输入、私有桌面、共享登记、内存预检与恢复协议。模拟仍暂停，只用于路线可行性，不能冒充实际战斗或产品。只测试有限摄像机路线与当前角色根集合，根增删改序即失败；任意嵌套属性/滤镜/像素原地变化尚未完整跟踪。

独立完整角色层与缓存重组进行像素对照，最终 GPU 读回叠 native UI 再与原生比较。允许记录失败后跑性能，但画面拒绝保持明确，不能部署。GPU 读回不是 Windows 实际窗口截图。自身 CPU/GPU 图像有预算和 finally 清理，原生位图仅借用不修改、不释放。

此配方运行后冻结；下一候选使用新目录。正式文件不改变。
