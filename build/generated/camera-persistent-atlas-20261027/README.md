# 持续合图与事件更新索引

1920×1080、原生模拟活跃、无敌人私有夹具、五视角真实画面、静/横/纵/组合三臂正反2880完整间隔。三臂为原生、原合图（固定页+背景合成）、新持续合图。页大小、像素合成算法、容量均保持；不是再调页参数。

旧版每帧先显示原图、隐藏所有页，再重扫全部sceneSurfaces并构造索引/字典，最后重新隐藏原图。新版保持合图绑定；依靠四父层ADDED/REMOVED事件和原生resident/redraws/evictions检测集合变化，缓存索引；按原生sceneViewport的整数格边界更新可见集合。每个实际页的源身份/修订仍检查并按需复制，父层效果与未知子节点可见性继续每帧检查。关闭、静止跳过和不支持的几何都恢复原生显示。

私有诊断范围：原生拥有图块坐标/裁剪、外观固定，RV/WB/LAD关闭。直接外部修改既有Bitmap几何但不改变集合/源身份的情况没有独立通知；未解决跨模组写入契约之前不生产部署。ADDED/REMOVED仅为集合通知，不伪装成像素内容通知；像素仍按surface.revision和source身份同步。两套8页各200MiB在计时前分配，准备成本单列，总内存400MiB；不称零加载成本。

五视角每种候选与原生RGB≤2/alpha0、恢复精确后才计时。旧版原样恢复绑定的高优先级回调保留；新版不调用逐帧恢复。所有时间、切换、资源准备记录保留。共享game登记、独立桌面/存储、4GiB提交/2GiB物理保护及526正式/13运行库输入闭包沿既有runner。需要后续真实移动战斗、破坏更新与完整兼容验收，不将本诊断当目标完成。
