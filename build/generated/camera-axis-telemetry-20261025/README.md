# 静止与分轴镜头的原生耗时对照

在已通过的camera-axis-motion 960帧原路线和全部画面、计数、输入、清理门禁上，仅增加960个原生telemetry帧标记和1个结束标记。World暂停，原生显示、时间轴和其他回调保留；不是实际无敌人行走或战斗验收。正式游戏和所有模组不修改。

复用已校准的camera-telemetry-v2记录器；它只临时独占本机.telemetry.cfg并自动恢复不存在状态，绑定127.0.0.1随机端口。每个标记的实际appid、序号、段号、条件必须完整吻合；原生微秒钟与960帧getTimer总时长须在20ms以内。全部原生流、配置状态、输入和像素证据保留。

每个原生命名区间按结束时间减span取得开始，对测量窗口裁剪并求区间并集，以免父子跨度重复计数。分别比较.rend.calc、.rend.update、.rend.paintbits、.rend.screen、.rend.screen.swap、.as.*与GC。类别之间可能嵌套，不能把表内数值相加当总耗时；呈现等待也不直接等于显卡负载。
