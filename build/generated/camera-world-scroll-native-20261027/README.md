# 在镜头内部省掉重复场景移动

上一轮不缓存滚动33.108→33.396毫秒，没有收益。帧末与下一次采样分别记录，确认每个
滚动区间下一次进入时场景x/y被原生镜头重新写为vx/vy。该原型每帧至少先移再归零，
尚未测试真正保持场景坐标不动的情况。本轮仅补这一项，不重复原样取优数值。

隔离宿主以当前A796为输入；Camera.calc只替换两处world.visual.x/y赋值，条件为其
scrollRect非空。SATS位置赋值、全部镜头计算、sceneTick、音效和鼠标坐标均保留。
null时仍调用原有setter。无新增字段、常量或寄存器；5770其他方法和1016类布局、
全部非ABC原始素材逐字保持。宿主属于诊断，不部署；没有真实玩法功能验收。

探针沿用固定完整路线准备、五视角75截图、480个ENTER_FRAME间隔和0/1/1/0顺序。
滚动时原生calc之后必须保持world位置0，下一入口必须精确等于上次设置，不再容许
原生重定位。记录最新EXIT_FRAME状态，要求每个区间都有对应状态；不把事件总数当
物理呈现次数。旧1281/480失败保留在原证据与独立复核中。

原RGB2/alpha0标准不变。已有无缓存滚动超界时仍记visualAccepted=false；本轮只测
这一不合格原型是否有值得修精度的收益。实际游玩、无敌人、战斗、RV、缩放与SATS均
未由暂停测试覆盖。所有正式文件、其他模组以及真实存档不变。
