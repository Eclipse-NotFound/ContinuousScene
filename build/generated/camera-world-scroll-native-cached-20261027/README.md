# 缓存滚动代价归因

复用06FC隔离宿主，仅Camera.calc的两处world坐标setter在scrollRect非空时跳过。
不缓存条件已完成480个区间，无收益；这轮只把条件改成此前未计时的缓存方式。
不是重复已失败的相同计时，不通过反复采样择优。

原RGB2/alpha0画面接受标准不变。已知缓存首视角曾maxRGB92，因此本轮允许继续的
仅是“未通过画面验收的原型代价测量”。明确记录visualAccepted=false与所有超界，
存图保留；如果没有明显收益就停止，不值得进入精度修复。不会部署不合格画面。

固定完整路线预备、独立自然三次精确往返、候选alpha相同/原生恢复精确仍为必需。
五视角75截图，0/2/2/0共480个ENTER_FRAME间隔；位置入口/最新帧末精确，计时无
原生预绘；保留所有长间隔。暂停模拟但时间轴继续，不能作真实无敌人或战斗FPS。
cacheAsBitmap标志不证明运行时实际采用了缓存或分配了何种位图。独立桌面/存储、
共享登记、4GiB可用提交内存和全部正式输入核验保持。
