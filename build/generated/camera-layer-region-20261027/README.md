# 一次角色层绘制，固定坐标的局部更新

前版7块分别重画耗时64ms，且完整角色层对照1364像素不同、RGB最大128/alpha24；保留失败，0帧率采样。整图查看没有整只角色缺失，差异主要在角色和光晕边缘，未证实边界缺失或不同draw平移是原因。

本版不再对7块各调一次整世界draw，而是先合并变化块范围，在固定整图坐标中只draw一次**中性、单位变换的原生角色层**，用目标clipRect约束写入，然后copyPixels分配至已有块并上传。避免在独立块平移之间改变绘制坐标。原生layer必须无mask/scrollRect/滤镜、alpha1、normal混合、颜色中性，否则失败。初始缓存和每次完整角色层oracle仍由原生world在同步遮蔽其他层时绘制，不能用候选自身当参照。

仍保留原生动画、暂停模拟，只检查时间轴驱动变化；任意像素写入、脚本变化、动态弹体与场景生命周期未接入。RGB2/alpha0全画面门槛和RGBA完全一致的局部oracle不变，未获部署资格。唯一AIR ID/私有桌面/共享登记/内存门槛沿用。
