# 修正测试入口后的 Stage3D 背景对照

上一留图轮证实：GPU纯输出为正确地图背景，但最终合成被原生主菜单遮盖。原夹具只设 mm.active=false，未执行公开 mainMenuOff；原生游玩入口会调用 mainMenuOff 移除菜单显示。

本变体在 newGame 前调用原版 mainMenuOff，随后核验 active=false，测试开始确认主菜单显示节点不在 main。各个计时条件均用同一修正入口；原有候选绘制命令、图层、坐标、采样及门槛不改。GPU纯输出仅首张留存，其余首次/失败三图规则保留。

早期与该夹具同源的测试包含被场景遮挡的菜单树，只能保留原范围内对照，不能直接当普通游戏的绝对性能。历史证据不覆盖，本轮结果独立记录。

仍须先通过13视角RGB≤2/alpha0/恢复精确，再进行960帧暂停镜头ABBA；不代表真实窗口混合合成或实际战斗验收。原生前景/对象/光照保持；无生产部署。
