# 统一探索历史的镜头参考

scout两模式进入测试平台前的位置不同，原版曾在目标房间等待且定位到(480,119)，大场景此前位于远处入口。因此retDark=false的已探索状态不一定相同，本配方检验这一具体假设。

保持同一3,3原有平台、角色位置、完整960镜头区间和原生运行。只在终结式隔离夹具准备时，将所有tile.visi/t_visi归零，调用原生setLight，并置isRelight让真实主循环从统一落脚点计算。没有改地形、遮挡或视距，没有持续强制视野。不恢复这些故意改变的测试探索状态，不保存或继续游玩。

记录统一前/后、五视角以及计时始末的整个本地48×25状态（visi/target/opac/遮罩RGBA/水）。这些观察在正式计时之外；没有增加逐帧扫描。始末相同不单独证明区间中从未写过BitmapData。像素、姿态、原版相机边界、全时钟和正式输入保护保持。
