# 活动角色图像合批绘制

前轮姿态缓存虽命中3065次，但1441次未命中、1438次淘汰，整体仍慢。本候选停止保存历史姿态；把同层本帧需要更新的根临时放入互不重叠的2048×2048图像区域，保持原父层，一次原生draw后分配各自小图。只同步修改视觉矩阵，不改逻辑位置或播放状态，finally恢复全部矩阵与可见性并逐项校验。根完整范围包含相机外部分，避免被截断的部分进入相邻区域。超出容量就明确失败。

角色仍按原顺序和根混合方式在GPU绘制，只有生成小图的阶段合批。此前的图像正确性问题未预设已修复；13次前置和5次后置画面对照以及独立完整角色层参照照常执行。变量含合批、取消历史缓存、改完整边界，不单独归因其一。

暂停模拟、保持Flash动画；仅可行性，不是实际战斗或OS窗口验收。独立桌面、存储、共享game登记、正式指纹与资源预算沿父配方。无正式部署。
