# 屏外高覆盖对象暂时摘树：区分可见性与变换传播

前一有效对照隐藏1170个屏外动画/滤镜根后反而慢12%，停止该可见性方案。本轮检验不同机制：这些对象不再挂在随镜头平移的世界显示树上，是否能避免祖先变换传播。它不同于以前只摘200个地形位图或30–45个远处敌人的实验。

只在终结式隔离实例中，沿前轮四条件960区间和严格资格，按逆序摘下候选、按原索引升序放回；所有六层原始兄弟顺序在恢复后逐一核对。原局部矩阵/可见性/alpha不改，边界计算对临时孤立节点使用原父节点坐标。记录摘下/放回数量，失败也恢复能确认归属的节点，不抢回被其他逻辑接管的对象。

暂停模拟、无 stop/play/goto；移出显示树可能影响原生帧调度和事件，不能把结果叫纯变换成本，也不能声称屏外动画行为不变。计时前后像素精确、恢复和输入门槛保持；若有收益，仍需专门的生命周期与真实玩法验证才可能成为产品。正式文件不改。
