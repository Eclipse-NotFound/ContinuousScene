# 镜头专项：屏外摘树约7%正向线索，尚无可部署修复

2026-10-27。正式 A796 / CS0.9.0 及模组组合保持；五次 AIR 运行、一次仅编译失败。两次有效计时各960连续区间，均在同一实例内正反对照。世界模拟暂停、Flash 时间轴未被显式停止，2032×1084、HIGH、120fps测试上限。下表是 ENTER_FRAME 间隔，不能称真实战斗或 OS 呈现帧率。

## 两个有效对照

| 原生 → 候选 | 静止均值 ms | 移动均值 ms | 移动 P95 ms | 移动最大 ms |
|---|---:|---:|---:|---:|
| 隐藏1170个屏外动画/滤镜根 | 20.579 → 26.017 | 33.896 → 38.008 | 42 → 51 | 114 → 117 |
| 暂时摘下1203个屏外动画/滤镜根 | 20.613 → 20.971 | 34.325 → 31.921 | 43 → 39 | 104 → 161 |

隐藏路线的两对移动都慢，分别增加4.517 / 3.708ms，平均倒退约12.1%，停止此方案。固定队列含554个带滤镜、991个含多帧的根，两者重叠。25740次可见性写入，26次审计，计时不全树扫描。10组候选/恢复图精确，150图及1×1边界探针释放；完整首组原生/候选 PNG 已查看。

摘树路线两对移动分别减少3.017 / 1.792ms，均值降低约7.0%。静止均值增加0.358ms，两个静止配对方向不一致；最大移动区间反而增加，不能只挑 P95 改善。1203根中560含滤镜、1020含多帧，343次边界变化观测、46次根帧变化观测。13233次摘下/13233次放回，全部六层兄弟顺序精确恢复。10组候选/恢复图逐像素一致，150图及边界探针释放；完整候选 PNG 已查看。

这两次实例的地图随机对象不同，不能把两个表行直接相减作因果收益；只各自比较同实例内的原生臂。摘树会影响原生事件和帧调度，观察到部分帧变化不能证明所有屏外动画时序不变，也不能把收益全部归因于祖先矩阵传播。当前只有进一步调查的线索，未部署。

## 原始失败和资格不足

- far-live-visibility：第一次原生往返图在纵移后有36像素/RGB78变化，候选尚未选根或写入，0计时；7图释放、清理通过。固定完整偏移预热沿用此前验证过的协议，随后仍三次精确返回，没有条件重试或放宽阈值。
- far-live-warm：选1189根、第一视角通过；第二视角资格变化，中止。0计时、28图释放；可见性恢复，但资格审计仍失败，原清理记录保留失败。不能从后继成功倒改这轮。
- far-live-cohort：编译失败，动态字符串键的前置自减不被 AS3 接受；未启动 AIR。修为显式 int 赋值，另目录 counts 冻结构建。失败源与日志保存。
- native-static-cache：扫描1964根，1392已缓存、281多帧、168已隐藏，其余含非矢量/特殊混合等；7个可缓存静态矢量根都在路线外，路线内合格数0。没有缓存开关写入，0计时，13图释放、清理通过。这仅说明本次夹具没有合格目标，不是缓存速度试验。

cohort/counts 的计时前剔除不稳定对象分支在两个有效轮中均未触发；不得声称该恢复分支已通过实际执行验证。
