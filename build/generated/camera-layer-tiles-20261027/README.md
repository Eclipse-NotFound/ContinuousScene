# 仅更新变化角色附近的小块

上一版活动动画分层缓存完整960区间，移动35.72→42.68ms倒退。角色层480次全层更新共10067ms（每次20.97ms，含上传）；其余8组计时没有重画。该失败保留，不重复同结构。

本版只将角色层分为512像素小块。观察同样的时间轴变化，取对应直接角色根的旧/新边界交集覆盖；变化处完整重画角色层的相应小块，其他块复用。保留同一层对象的顺序和重叠，旧位置同样清理。每组像素检查另完整画一次原生角色层，与全部缓存块重新拼合的图逐像素比较，**必须RGBA完全相同**。不以全画面已有RGB误差放宽此局部门槛。

边界由pixelBounds与getBounds并集外扩16像素，只是待验证的局部假设，不称通用滤镜证明。原生世界平移需1倍整数。缓存覆盖整个预备路线；跨路线移动、位图像素写入、任意脚本变换、子弹和地图生命周期仍未接入。没有停止原生动画，模拟仍暂停，不是实战验收，不部署。

同实例960连续区间/反序配对，保留全部长帧。正式526文件与13运行库只读，测试使用唯一AIR ID、私有桌面、共享登记与内存门槛。继承所有原生自然/恢复检查及RGB2/alpha0全画面门槛；GPU读回不是OS窗口截图。

pixelBounds官方说明只保证舞台中的外框，不能代替本轮的完整原生层像素对照：<https://airsdk.dev/reference/actionscript/3.0/flash/geom/Transform.html#pixelBounds>。
