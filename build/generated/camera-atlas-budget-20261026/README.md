# 分帧建立地形合图候选

以short-combat两轮约8–10%正向、首次150MiB分配281/212ms为依据，只修改合图建立调度。每次正常update最多新建一张1280²位图；尚未四层齐备的页不复制和呈现；本视口所有页齐备前保留原生画面。原有复制、可见性、几何/缩放/SATS回退、LRU和清理保持。测试专用forcePresentation仍可一次建齐，用于相同帧像素检查，真实计时不调用force。

原生敌人、子弹、碰撞、移动和四段120帧保持；85冻结源只变主探针版本及SceneRasterPresentation。每帧记录分配数量和部分页状态，保留全部准备期和尖峰。不得将准备期删除后计算收益。

只在隔离副本验证，未部署。页面调度变化须通过真实移动、资源守恒及像素/生命周期验证，不能靠编译或较小单帧分配数量判断流畅。
