# 视野内静态矢量根的原生缓存对照

这不是已失败的整个 world 缓存，也不是手动 draw/上传纹理。只在六个原生物件层的直接根中，选择整棵子树均单帧、正常混合、无遮罩/滤镜/已有缓存且含 Shape 的对象；必须与整条路线保护区相交。最多32MiB估算栅格面积、单边2048像素。只写 cacheAsBitmap，原生引擎继续处理动画与内容失效；不换父节点、纹理、矩阵、显示或模拟状态。

按原生静止/移动、缓存静止/移动正反960连续区间；计时前后五视角共10组图片。候选 RGB 超过2/255或alpha变化明确拒绝，但允许保留暂停归因计时；原生恢复仍必须逐像素精确。固定完整偏移预热和三次精确自然往返不变。资格变化、缓存状态外部变化或父节点/局部姿态变化均中止，全部自有开关恢复。

仅改变终结式隔离实例；沿登记、独立桌面、唯一存储、内存检查。不是实际战斗/无敌人游玩/OS窗口验收，不直接部署。

依据：[AIR cacheAsBitmap](https://airsdk.dev/reference/actionscript/3.0/flash/display/DisplayObject.html#cacheAsBitmap) 适用于静态矢量平移，但会按像素对齐；文档不是本游戏效果或提速证明。
