# 实际屏幕尺寸远景缓存候选

先验证假设，不部署。原生cacheAsBitmap曾更慢；本方案明确绘制到屏幕像素尺寸，随后使用单位比例的Bitmap呈现，保留地形和全部对象。

仅接受静态单帧、无滤镜/遮罩、父链变换与颜色中性的远景；先在透明缓冲区按原生矩阵和颜色绘制，证明屏幕范围每像素alpha为255，才创建不透明副本。若存在透明像素则失败，不填充掩盖。保存子树身份/变换/颜色/帧数/位图引用，每次呈现检查；不宣称能检测任意Graphics或BitmapData内容修改。只用于暂停假设测试。

五视口原生/缓存/恢复，容差RGB2/alpha0、恢复精确。完整960帧正反序静止/移动对照，八个地形计数不变。缓存由计时前画面检查建立并保留，报告首次创建成本；计时不复制/分配，终态释放全部。准备与实战生命周期需后续独立验证，不能由此部署。
