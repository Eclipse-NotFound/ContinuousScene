# 固定角色缓存及直接源绘制

上一候选每次动画边界变化都重新分配图像和纹理，且逐根通过父层绘制造成明显倒退。本候选保留已分配图像，只有超出预留范围才扩展；不带自身滤镜/遮罩/裁剪的根直接绘制源图，显式传入本地矩阵和颜色，子孙效果仍由原生绘制器处理。有根效果时保留原父层隔离的兜底。

改变两个机制，不把结果单独归因于其一。新增直接/父层路径计数和耗时，记录所有图像/纹理分配。原生现有 BitmapData 继续只读借用、每次重新上传。

仍为暂停模拟、保留动画的有限镜头路线对照，不是实际战斗验收。13次独立像素参照、960帧事件区间、输入指纹、隔离桌面/存储、共享登记和内存门槛沿父配方。图像差异不合格也可计时，但绝不部署。已运行配方冻结，正式安装保持。
