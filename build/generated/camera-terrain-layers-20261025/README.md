# 镜头移动时的前后地形层归因

原生记录已验证镜头运动的额外耗时集中于绘制区间。此处仅在私有测试实例中，对四个稳定地形父层的 visible 属性做可逆开关，区分后方地形、前景/水层与其他显示的成本。所有八段均使用同一连续镜头路线，顺序为原生、后层隐藏、前层隐藏、四层隐藏、四层隐藏、前层隐藏、后层隐藏、原生，各120帧；原世界/实体显示和模拟对象不删改。不是消除地形或降低画质的产品方案。

沿用已验证960帧夹具、八项预绘计数逐帧不变、固定玩家、私有窗口、正式输入和清理检查。五视口分别在同一回调内捕获原生、三种抑制与三次恢复，要求每种恢复精确相同、抑制确实影响至少一像素；全部35张释放。记录实际父层可见性，避免只看请求。仅这些地形父层变化，不重试此前全世界隐藏导致武器图像无法恢复的控制，也不修改宿主二进制或开启telemetry。

测试源由 camera-axis-motion 的冻结转换精确派生，Main保持原转换，只有Main与新helper两源不同于85源种子。RC pin遵循负责人当前2C49/animfix1及verified.json；正式文件不改。结果只用于后续选定优化对象，不是实战收益。
