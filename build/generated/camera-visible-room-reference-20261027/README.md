# 可见原版房间镜头参考

仅隔离诊断，无产品修改。保持模拟运行，移除测试场景敌对单位与已有子弹；不放入六敌人夹具。正常房间与大场景都选第2列第3行，先验证原有平台和身体空间，再放置玩家一次。地形不改，原生镜头边界不改。

脚本横、纵、组合移动采用同一局部路线；全960区间保留，分解优先级监听区段。每视角保存完整PNG并要求正文可见覆盖至少30%，实看后方可作为可见内容参考。图片编码在计时前，之后稳定60帧。逐帧要求角色在屏内且镜头没有被边界钳制。

窗口1280×720，120fps为诊断上限，不是玩家实际FPS。两模式独立世界的动画/随机物件可以不同；同地形哈希、相机路线、主程序字节与配置另外核对。不属于自然跳跃或实战验收。
