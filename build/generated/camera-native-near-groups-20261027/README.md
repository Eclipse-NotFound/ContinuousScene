# 近景相邻物件的原生分组缓存候选

不是此前整个world缓存，也不是逐物体手工光栅或冻结动画。只取原生Box/Bonus持有的vis/shad，保持原显示顺序中连续的根，限定整条镜头路线附近。组包围盒最长768px、最多16根、估算总缓存≤64MiB；根及后代仅normal混合，无mask/scrollRect/3D，只接受已核四种滤镜。

新增Sprite坐标恒为0、原根局部矩阵不动；cacheAsBitmap由原生运行库负责子内容失效。未更改敌人产品逻辑、未stop/play、未设置子可见性。仅在独立无敌人夹具运行；不是战斗或完整兼容验收。分组原始/缓存切换逐次核逻辑顺序，目标若被原生移除/替换/重排则中止，不推断新父节点合法。

完整1920连续区间，原生/缓存各静、横、纵、斜两段，正反配对，切换和所有尖峰保留。整条路线预备两种状态，五次同回调四图：原生重复精确、候选RGB≤2且alpha0、恢复精确。第一视角保存PNG。仍需真实窗口、原生互动/损坏/门/藏身/念力与战斗/RV测试后才能讨论部署。
