# 视野外静态根节点的显示开销

新前提：相同移动路线中 world.alpha=0 约21.9ms，world.visible=false 约13.8ms。
本实验仅检查保留完整画面时能否拿回一部分差值，不把隐藏地图当成产品。

预备原生路线时记录实际视口并集，四周扩大320px。仅一次盘点六个物件层的直接子节点；
仅选原来可见、整棵子树无播放中的多帧动画、无遮罩/被用作遮罩、滤镜、3D或非普通混合，
且 bounds 完全在路线并集之外的根节点。读不全就跳过。对象不摘树、不包装、不停止动画，
不改逻辑链；仅条件切换时设置 visible。帧内不扫描全部对象。

固定原生预备和三个精确自然往返不变。五视角中隐藏和恢复均须逐像素一致，55张截图
完整释放。四窗口 native/culled/culled/native 共480帧，同一水平/垂直镜头路线。
边界切换成本记入实际间隔；检查根状态、父层身份和全图绘制计数。未覆盖的帧内状态
变化与冷启动不据此宣称通过。暂停世界、保留时间轴和回调，只作诊断；无产品部署。
