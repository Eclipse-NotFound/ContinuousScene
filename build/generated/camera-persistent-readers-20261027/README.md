# 视野地形读取契约验证

持续合图跨帧保留，因此地形原图已改、合图尚未更新时，RV D44的前景读取可能读到旧合图。本实验复制正式D44的RVWallSurface到两个隔离类，原读取逻辑保持为对照；候选通过只读函数获取本帧应可见的原生图块和外来节点，忽略自身合图。裁切、颜色、透明度与异常绘制回退仍沿RV的原函数。

真实Flash夹具分别验证改图前、原图改变但缓存未同步、缓存已同步、恢复原生四状态。旧读取必须在第二态产生差异，其余相同；新读取四态全部逐像素相同，且不复制合图、不切换原图可见性。保留16缓存状态/5实际地图视角的既有功能检查，拍图后结束，不运行计时。

这是候选读取接口的功能验证，未改RV源码/正式SWF，也未接生产入口。完整视野遮罩、WB、任意图块几何修改、正常/大图切换、缩放与长时资源仍需另验，不能据此发布或声称整体兼容完成。
