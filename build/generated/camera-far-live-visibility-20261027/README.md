# 屏外动画与滤镜根的原生绘制归因

旧 far-maskguard 只覆盖 274 个单帧、无滤镜根，不能回答其余动画与阴影对象的成本。本轮只选择先前被排除的动画/滤镜根，仍保留单帧无滤镜根作为原样背景；不重新包装或移动父节点，不停止时间轴，不改变模拟对象。

固定路线外加 320 像素保护区。保守边界把各子节点的几何和允许的模糊/投影/发光/颜色滤镜递归合并，再变换到世界坐标；不支持的滤镜、遮罩、特殊混合、3D 或空子节点不入选。generateFilterRect 仅用于边界估计，像素精确检查仍为独立门槛。

同一世界四条件：原生静止、原生移动、屏外根隐藏静止、屏外根隐藏移动，正反顺序 960 个连续区间，保留切换、审计和所有长帧。计时前后各五视角做固定预热、三次自然往返与隐藏/恢复精确图像检查。原生准备计数必须保持不变。资格和边界在切换时审计，不能证明所有中间回调状态，故仅作隔离归因，不直接部署。

时间轴继续运行，世界模拟暂停；这不是实际战斗、无敌人游玩或 OS 窗口帧率验收。正式文件不修改，沿共享 game 登记、私有桌面和内存预检。

API 参考：[BitmapData.generateFilterRect](https://airsdk.dev/reference/actionscript/3.0/flash/display/BitmapData.html#generateFilterRect())。
