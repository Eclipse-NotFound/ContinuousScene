# 镜头移动的图层合图对照

复用冻结的 SceneRasterPresentation（C0E40368FD8BF6FE1413EC4C8D533C7034B18297AEB35119FBFEC4ADD5D93175），把四个原生地形父层分别合为视口附近的一张位图，保留层间的角色等显示对象。原生位图仍是内容来源，不改变模拟对象。既有战斗对照受火力和预绘混杂，尚未在暂停世界、整数镜头、零预绘变化条件下测过此方案；本目录补该诊断，不重写呈现算法。

从 B7ED 冻结收据的85源派生86源，仅改主探针并增加 SceneCameraRasterTrial。helper SHA256：3C88E94C4A6C6EC0B3D26C0CFC6C7F0EE478CB8CF2D1B5F5ECC785B2CC10BE30。五个视口按原生/合图/恢复检查像素；采用用户允许的RGB每通道最多1/255差、alpha零差，恢复仍须完全精确。缩放、小数位置和震动未纳入此容差授权范围。

随后8×120帧连续计时，顺序为原生静止、原生移动、合图静止、合图移动，再反向。120fps、暂停World仍保留其他回调/时间轴，原生World与helper都调用Camera；只作此条件下的差额诊断，不是实际游玩FPS或发布验收。预绘/驻留/失配计数须整段不变，玩家位置不得改变，所有区间连续守恒。

计时包含原生/合图切换、首B建图复制以及B回A释放。copies只数原生cell到合图的复制，不含旧合图向新合图的整图复制；rebuilds每次对应四张位图创建。两者不是完整耗时，最终看全区间墙钟。长距离跨缓存边缘仍需另验，不能从短距离直接推断无重建卡顿。

runner通过共享测试登记、独立AIR ID/存储和私有桌面运行，保留4GiB提交/2GiB物理预检及512MiB运行保护。正式文件不改动。
