# 缩小地形透明边缘的原生绘制范围

假设：当前四类地形表面均以 320×320 中心矩形呈现，前景、积水及部分背景含大块完全透明区域。用源位图 alpha 外包矩形与原中心相交，只缩小原 Bitmap 的 scrollRect 并补偿 x/y，可能减少镜头移动时的混合像素。

不拼图、不分配地形位图、不复制像素、不隐藏对象或光照，不改变排序、地形原生数据、逻辑/碰撞。外包矩形保守：仅省略可证明全透明的边缘；洞内透明仍保留。空面使用零大小裁剪。源修订变化时重新计算。正式实现仍需考虑脏块/回退/退图；本轮只验证已预热的暂停世界。

13 视口（含单像素偏移）RGB≤2、alpha0、原生恢复完全一致后才进入960帧原/裁剪静止与移动对照。记录可见矩形面积和实际修改数，不把矩形面积当实际渲染像素。真实战斗收益未验证。主菜单正常退出，共享登记和正式输入守恒保持；无部署。
