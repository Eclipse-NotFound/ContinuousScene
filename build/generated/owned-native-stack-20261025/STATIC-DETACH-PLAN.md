## 首版唯一白名单与可逆操作

1. 只接受准确 `fe.loc::Box`，不接受子类；`wall>0, door==0, inter==null, scrDie==null, un==null, lurk==0, molnDam==0, radioactiv==0, light==false`，当前存活、非 invis、属于当前 loc 且仍在逻辑链。要求 levit==0、levitPoss==false、无投掷/支撑运动、X/Y 与 dx/dy/cdx/cdy 连续稳定。字段不可读或状态未知即排除。不把“当前停稳”当固定，不猜对象 id；预检输出实际 id/类/字段和合格根数，形成该次明确名单。
2. **仅主体 vis**：必须为原 `visObjs[0或1]` 的直接且独占子节点；主体及子树为单帧静态素材，无 mask/filter/scrollRect，无独立灯光或特殊混合，保留原 cache、alpha、颜色与变换。多帧即使 isPlaying=false 也不收。影子原生必带滤镜，留原树；Bonus、Trap、CheckPoint、门、容器、移动平台、BackObj、单位、武器、粒子全部排除。实际素材的帧脚本与 ADDED/REMOVED 消费者仍需核，不能靠单帧数证明没有事件副作用。
3. 性能窗只纳入位于整条实测相机扫过区域之外、连同显示 bounds 留320px余量的根，不做每帧全树扫描/拆装。阶段切换才 `parking.addChild(vis)`；parking 不入舞台。保存 root/owner/parent/loc 身份、原次序和存活邻居。恢复用存活邻居确定原深度，不能仅使用已过时的数字下标；顺序冲突则本轮无效。A/B执行相同资格核对，保留切换成本。
4. 不调用对象 addVisual/remVisual/stop/play/setNull，不改逻辑链、X/Y、碰撞、伤害、交互或实体数量。原生替换/移动/删除 root 时不得抢回或复活；恢复其他仍属本探针的根，并明确终止该窗。死亡/换图等状态的完整恢复规则，在前述源码缺口闭合前不实现。退出、异常、SATS/Pip/暂停、场景身份变化必须回原生且核零遗留。

## 最小验证与停止线

- **先只读清点**：合格数量、节点规模及真实父层；若极少或素材资格不明，停止，不为扩大覆盖改白名单。结合原生线程采样再决定是否值得构建，不预设有大收益。
- **组件先于计时**：同帧完整视口摘前/摘后/恢复严格像素相等；同时检查主体/影子/全部非目标根身份和属性、原次序；无需像素容差。摄像机走近/越过保护边界前必须恢复，返回远处再摘；缩放、震动、SATS截图、异常及重复进图后不得出现缺块或旧根回插。
- **逻辑与交互**：保持目标对象/逻辑链/碰撞包围框、碰撞和射线结果一致；验证伤害/销毁时不复活根。门与容器保持排除，仍以原生 E 开关门/取物作旁路回归，核门图像、Tile碰撞/遮挡及层级不变；不能以“本轮未互动”代替通过。门变化/脚本触发导致资格改变须保守恢复。
- **一轮成本上界**：只有组件和数量支持才复用既有真实 SMG/玩家实射连续1200帧的 ABBA，全部原物理、AI和长帧保留；分别报告实际摘根数、切换/核查成本、火力/活动/预绘与完整计时。不替换成隐藏，不测试休眠敌人，不以跨轮均值作净收益。无同向、足以解释卡顿的改善即停止；即使成功，也只证明本白名单，不能直接生产部署。

本页不承诺逻辑/画面已验；清理要求是所有自有根恢复或被原生合法销毁后不再持有，parking/记录归零，原宿主与模组输入保持。没有为该方案启动任何游戏或新构建。
