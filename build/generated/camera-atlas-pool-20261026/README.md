# 地形合图固定缓存池候选

现有分页合图短窗两轮约8–10%正向，但150MiB集中分配仍出现281/212ms长帧；逐张分配实测也在准备期出现291ms，不能视为修复。

本候选在计时前一次预留8页×4层×1280²×4字节，即200MiB。运行中只借还这些页，清空旧页再复用，不创建BitmapData；退出/关闭功能完整释放。尚未准备好、换位置或显示父层变更时保留原生画面，需要加载入口重新准备。不会在普通update里补分配。

ABBA诊断的A只恢复原生呈现并保留不可见的池，不更新缓存像素。真实正式关闭仍调用clear完整释放。A因同进程而有候选内存驻留，不能把该对照单独当完整部署验收。准备耗时和内存增量独立记录，所有480计时帧和切换成本保留。原生6敌、双方弹体、加速、冲刺、击退、碰撞保持。

测试专用useNativeForTest只负责ABBA关闭呈现，不拟作为产品公开开关。固定页像素内容/层序/几何资格沿已验证AD472C79，仍需本候选视觉与生命周期实测。仅隔离候选，不部署。
