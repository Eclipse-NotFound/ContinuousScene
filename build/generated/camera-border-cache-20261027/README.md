# 外围边框缓存对照

只在独立实例中比较原生四条外围边框的 cacheAsBitmap=true/false。依旧运行正常世界循环，视口围绕角色，五个视角必须有实际地形。静止、横、纵、组合移动各 AB/BA，1920 个完整间隔，保留切换成本和所有尖峰。无敌人隔离夹具不是实战验收；不改变正式文件。

每次变更仅四个布尔缓存标记。五视角原生重复、关闭缓存和恢复截图比较；最多 RGB 2/255，alpha 必须完全相同。清理恢复原值，不重挂父节点、不改变时间轴。

当前主机和 RC 版本、526 正式输入及 13 运行库均由已有 runner 固定；共享登记、独立桌面、唯一存储、4 GiB 提交和 2 GiB 物理余量。冻结后不能原地改配方。
