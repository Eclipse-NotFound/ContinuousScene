# 完整世界固定画面 Stage3D 可行性上限

区别于已停止的局部背景/地形显卡绘制：把完整 world（含角色、前景、水、明暗）预先画成固定图并切为最多 1024² 的显卡纹理，显卡按原生整数镜头坐标移动整幅画面，原生 world 与远景仅在候选窗口隐藏，界面保持原生。不是产品候选，不部署。

所有条件共用同一个暂停世界；扫描 world 与远景下的多帧 MovieClip，只停止当时正在播放的时间轴，两组均保持相同姿态。窗口边界及截图前核验帧和播放状态，清理只恢复本次停止的时间轴。其他回调仍可运行。即使有收益，也只是把所有动态画面免费缓存的上限，必须另外补齐真实动画与战斗才能推进。

预先准备全部路线与固定偏移；五视角各一次固定完整原生预备及三次精确自然往返后，一次性截取完整路线包围矩形。捕捉时同步关原生地形可见性裁剪，finally 恢复标志并调用原生 sceneTick，不改碰撞或对象。包围图最多 4096²，纹理总额最多 96 MiB，计时前完成全部上传和 CPU 位图释放。

13视角逐个固定预备、三次自然不变检查、候选 RGB≤2/alpha0、精确恢复；全部合格才计时。第一组及失败截图保留。5×13+13×15=260张像素检查图须释放，不把预备图片变化抹成相同。8窗口每120区间，顺序为原生静止、原生移动、GPU静止、GPU移动及反向，连续计时、不剔除长帧。八项原生预绘计数在计时中须不变。

唯一 AIR ID、私有桌面、共享 game 登记、4 GiB提交内存/2 GiB物理内存门槛，正式526文件/13运行库保持。当前根宿主 A796，不用 scrollRect诊断宿主。当前原生入口 mainMenuOff 保留。

像素比对是 GPU 读回再叠原生界面，尚不证明 Windows 真正混合呈现。当前仅性能可行性诊断；必须有真实窗口证据、动画、子弹、交互、视野及恢复验证后，才能成为可部署路线。冻结画面帧间隔不能声称实际游戏帧率。
