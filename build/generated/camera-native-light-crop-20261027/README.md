# 原生全图明暗位图显示范围候选

暂停镜头同区域对照显示，大图静止比原房多约8ms；已观察脚本仅约1.5ms，移动增加主要在帧事件间隙，不能由此指认GPU。代码中原生visLight把整图lightBmp放大40倍，连续图241×128光照像素对应约9640×5120世界范围，默认关闭的是外部光与暗模组而非这一原生层。

本候选仅给原生lightBitmap设置视口附近scrollRect，并同步x/y保持采样坐标不变；视口外多保留两格，保留双线性平滑。原始lightBmp、所有光照运算、明暗样式和层序不改，零复制/新位图。只在可见、原生40倍父变换、无其他裁剪/滤镜、已加载大场景下做测试；结束恢复原x/y及无裁剪。

十三视口包含五处大范围与八处逐像素往返，RGB≤2/alpha0、原生恢复精确；960帧静止/移动正反序、八个原生计数不变、资源及输入守恒。先测假设，不部署；窗口变化、SATS、动态光照、全部模组和实战另验。
