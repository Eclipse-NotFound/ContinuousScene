# FocusManager 整体关闭成本上界 v3

仅隔离诊断，不是生产候选。采用 B7ED/39A 的原 85 文件冻结源，仅增加可逆探针挂点与一个 helper；原 A/B/B/A 四段各 300 帧高速移动、六敌 LMG、玩家 ASSR、完整连续时间不变。

v1/v2 分别错误要求舞台焦点/lastFocus 为空，均在 0 样本时失败且未关闭管理器。v3 从真实已有 UIScrollBar 取得唯一 FocusManager，严格要求 form 为同一 Stage，A 的舞台焦点与 lastFocus 均为 Stage、B 的 lastFocus 原生清空；默认按钮为空，菜单/Pip/SATS/控制台关闭。B→A 用公开 activate、短暂 Stage.focus=null、setFocus(Stage) 恢复自然 FOCUS_IN 状态，不写私有字段或伪造事件。每帧检查身份，原始失败记录不修改。
