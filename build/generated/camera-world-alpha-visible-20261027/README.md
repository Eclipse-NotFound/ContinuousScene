# 地图透明与停止显示的区别

新证据表明固定原生预备可以通过精确自然往返和恢复检查。沿该条件比较同一地图父层的
原生、alpha=0、visible=false、二者同时，四组都走相同镜头路线。不是改隐藏方式逃避旧失败：
旧冷态失败保留，本轮每视口仍须三次自然往返与每次显示恢复逐像素相同，失败即停止计时。

先前alpha0使移动约32→22ms，但透明对象仍存在，尚不能确定停掉显示是否减少更多处理。
本轮只查这个差异；不删对象、不改敌人行为或正式产品。暂停世界而时间轴仍可继续；其他回调
可能观察visible，因此帧间隔差不能直接叫纯渲染耗时。5视口75截图、960帧、完整清理与输入核验。
