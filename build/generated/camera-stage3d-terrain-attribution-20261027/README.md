# 所有地形层的硬件绘制归因

先前只将远景/后景放到GPU无收益，仍保留原生前景。角色/上层单独控制仅解释约4.8ms。
本轮把四类地形位图按后景1、后景2、前景、水的顺序送入GPU，其余对象仍由原生绘制。

**这是故意不保持遮挡顺序的归因实验，不是产品候选**：原生对象会出现在前景地形之前，
并未解决分层混合。候选截图差异全部记录，不以它作画面通过；只要求返回原生后精确恢复。
若仍无明显收益，停止扩大硬件地形路线。若明显提速，只支持继续研究正确的分层合成，不能部署。

先固定一次自然镜头预备，再三次精确自然往返，才作GPU切换；13视口、143截图全部释放。
960帧同时比较静止和移动，保留所有长帧/同步成本。仍是暂停世界，不是实际战斗或用户画面验收。
