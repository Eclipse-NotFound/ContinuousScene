# 每帧完整视口重绘与上传代价

完整固定世界上限对照已得到960区间：原生移动29.658→GPU移动12.092ms，两配对减少16.892/18.242ms；但动画未更新、13视角RGB92–253不合格、最大130ms长帧仍在。不能把该结果称为可玩版本或实战收益。

此轮保持同样的固定姿态与原生镜头路线，只改变GPU图像来源：预留一张2032×1084透明CPU位图和一张相同纹理，每个GPU区间原生绘制整个当前视口再上传。原生裁剪保持，不再临时关裁剪或截全路线；远景仍独立固定纹理，界面仍原生。所有分配在计时前完成；每帧记录绘制与上传时间、次数，不能漏掉这部分开销。

这不是动态战斗测试，而是确认最简单“每帧全图重画”方案的计算代价。若明显抵消固定缓存收益，就不直接接入实际游戏，转向局部变化更新。预计13次像素候选刷新＋480次计时刷新=493，纹理上传495次（2次初始）；CPU位图2张、纹理2张，均释放。候选画面不合格仍明确保留，原生自然往返与恢复要求不变，RGB2部署标准不变。其他动画恢复/独立桌面/本体指纹约束沿前一变体。
