# 活跃模拟下的无敌人同房间镜头基准

目的：补齐原版/大场景的横向、纵向镜头移动对照，避免把暂停世界、未关主菜单或仅按键请求当作实际移动。

沿冻结29AF 85源，仅改驱动并新增helper（86源）。两模式同一SWF、地图种子20261019、房间2/4、实际1280×720、原生setZoom(0)和完全相同的120点路径，8×120区间：静/横/纵/组合/组合/纵/横/静。私有窗口初始化即显示，真正mainMenuOff，不禁用原生暂停；模拟始终onPause=false，120fps诊断，所有计时/原生calc/观察成本保留。正常帧速、缩放、镜头/显示状态在终态恢复。

驱动在战斗预热之前进入helper，以已核SceneEncounter的原生移除方法移除本隔离地图敌对单位（包括刚生成的六名夹具射手），不触发死亡/掉落；清除已有Bullet，清空控制器。每帧确认无敌对单位、模拟正常。移除只发生在独立AIR/独立存储；敌人不恢复，实例终结，不能作为产品减少敌人的方案。中立NPC/友好角色仍保留并记录。

相机用原生camRun+calc驱动，玩家只保留此前一次初始放置，之后原生物理持续；这不是自然跳跃/跑动实玩验收。完整路线预热、60帧稳定后计时，要求原生预绘计数无增长；五组同回调原生绘图往返精确、10图释放。跨模式比较还需独立核相机轨迹仅相差房间偏移、地图/走廊指纹和当前输入。
