# 原生镜头分轴诊断

用户要求无论有无敌人，都以镜头移动为核心。此轮固定同一已生成场景和玩家，不移除实体、不改变镜头路径以外的画面条件。正向测试静止、横移、纵移、原组合路线，再逆序，共960个连续间隔。每段120帧，逐帧证明实际X/Y运动轴与目标一致。

World模拟暂停，Flash时间轴、其他帧回调和原生Camera调用仍在；120fps只用于诊断，不是真实无敌人行走FPS。由固定29AF的85源变成86源，只改Main接入并新增helper，保持原生显示方式。沿路线预绘直到八项计数整遍稳定，计时期间它们必须逐帧不变。原窗口/镜头/暂停/显示矩阵完整恢复，正式文件保持。

不再隐藏世界。之前camera-world-motion两版0性能样本：v1恢复1545像素差；v2三张连续原生图全等，隐藏后的两张恢复图彼此全等却和原生有2612像素差，位于X626–1020/Y537–612的武器区域，maxRGB206/alpha0。原因未证，不把失败改为通过，也不把这种控制加入本轮。六张PNG与原始result保留。

本轮五个视口只做两次连续原生截图，要求逐像素全等，10个截图位图全部释放。计时中world.visual始终可见，私有NativeWindow始终可见。保持独立AIR/存储、共享测试登记、内存门禁、526正式输入与运行库冻结、失败和全部尖峰保留。后续仍须真实行走和战斗验证，诊断不部署。
