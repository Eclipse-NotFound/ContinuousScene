# 合图真实移动战斗短窗对照

用户要求镜头移动无论是否有敌人均优先解决。原生分轴和telemetry已复现绘制开销；地形层/远景新试验未形成可部署优化。既有分页合图暂停移动有正向线索，但旧实战4×300因持续原生击退越平台而不完整。

本轮只把同一85源冻结实战探针的四段长度从300改为120，总480帧，更新版本标记；分页helper、六名SMG10敌人、武器参数、原生键盘移动/加速/耐力/击退、碰撞边界、预热、射击和清理均原样。没有传送纠正、修改地形、删敌或减伤。时长缩短为了先得到完整成对实战数据，不能外推长时/全配置。两段原生与两段候选各240帧，所有初建缓存和切换尖峰计入。

结果解释仍检查真实冲刺、敌我实弹和同时多子弹，并保留各段火力/预绘差异；首轮正向不等于生产门禁。渲染helper保持AD472C79，单位整数几何资格以外原生回退。RGB2/alpha0的暂停证据不能替代实战视觉检查。旧失败与长窗数据不改。本目录只准备测试源，不部署。
