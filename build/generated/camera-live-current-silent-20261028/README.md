旧 r1 在调用 AIR 进程构造器之前失败：独立 APPDATA UUID 根被 Windows 重定向到 Codex 的 LocalCache/Roaming，而旧检查把它当作越界。旧目录及失败回执冻结；prior-recipe.json 固定其六个输入的摘要，准备时重新核对。

新 silence.py 只接受普通 APPDATA 私有根或已经观测并逐级核对的确切 Codex 私有缓存根，同一新 UUID、排除重解析点、不覆盖既有目录和配置。当前 Python 包身份 API 返回 15700，不声称 Python 有包身份；该退路明确标为已观测 Codex 文件虚拟化。写入后从实际路径回读原生 Snd 三个音量均为 0。仅覆盖原生 Snd，不声称所有模组音频或运行时 SoundMixer 已静音。

run.py 在静音准备或最后内存预检失败时，明确记录“未调用进程构造器”，只清除此时登记器的 launching 标志。进程构造器一旦被调用仍按原登记器保守处理，不能因此释放未知子进程。
