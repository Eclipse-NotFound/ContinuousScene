# 原生战斗中的纯地形分层成本

从已实测 29AF SMG10 探针的冻结 85 源派生，仅 Main 修改并新增默认包 `SceneTerrainLayerTrial`，共 86 源。保留原 4×300 连续 ABBA、原生冲刺/击退/开火及所有场地门禁；不新加定位、复位、帧率控制或世界暂停。旧分页类保留原字节，但本控制不执行它。

`terrainfront` 只隐藏 `sceneSurfaces().bitmaps[0]`，`terrainback` 只隐藏 `[1]、[2]` 中原本可见的原生地形 Bitmap。绝不隐藏父层：否则 visFront 下的单位也会随之消失。水、雾、对象层及其父层的直接/有效可见性在每次操作前后核对不变；原生 Bitmap 的 parent/bitmapData 身份全部核对。A/B 执行同样扫描，扫描及恢复成本保留在连续墙钟内。

扫描绑定按 Bitmap 身份复用，scratch 节点数组也复用；必须先恢复上一帧所有自有隐藏记录，才能重填下一帧记录。同一 Bitmap 的 parent/data/layer 身份变化即失败；离开原生 surface 集合的记录当帧释放，终态清空字典和数组，避免观察器保留卸载的原生缓冲。`bindingsCreated/bindingsReleased/liveBindings` 明确记录分配及清理。

最高优先级 ENTER_FRAME 恢复上一帧自有隐藏节点，原 phase4 的呈现控制位置临时隐藏目标，随后才取原连续时间戳。恢复时再次核对 parent/data/被隐藏状态，出现其他写入冲突即记录失败，仍尝试恢复全部节点。每帧记录当前及 previousApplied、相机实际矩阵、四层前后可见数量、非目标/对象层状态及原生预绘计数；终态恢复幂等。初始化之外不改任何 AI、物理、按键、武器、对象数组或像素数据。

这是主动缺失地形画面的成本归因，不是视觉等价、可发布优化或真实玩法验收。快照是探针回调位置的状态；其他模组同帧晚期回调仍存在，下一帧若覆盖了自有隐藏节点会使本轮失败。

上述结果不支持把背景或前景地形单独作为主要瓶颈。背景只有小幅线索，前景没有观察到改善；火力、活动和时间趋势不同，不能将差额精确解释成纯绘制成本，也不能把两进程差额直接相减。暂不推进部分透明面积裁切或重开既有地形缓存方案。下一窄方向是保持原生可见画面的 direct/cpu 送屏路径对照，另行准备；本目录没有可部署优化。
