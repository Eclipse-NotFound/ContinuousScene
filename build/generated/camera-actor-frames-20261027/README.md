# 已观测动画姿态复用

继承 actor-sprites 的原父层绘制，不继承 actor-direct 的画面失败路径。单位层与 visObjs[4] 的活动效果按独立根缓存。根据根变换/颜色、相对覆盖范围、已跟踪 MovieClip 身份与帧号复用此前的小图；只排除整数平移，保留亚像素相位。缓存上限24MiB/512项，按最近使用淘汰；单项超过2MiB不保存。位图图像仍只读借用并每次上传。

这不是完整的产品失效模型：任意脚本对子节点属性、graphics或原地位图内容的修改尚未全部跟踪。模拟保持暂停、动画继续，不宣称正常AI/实战支持。

计时前13次像素验证，960区间计时后再做5次像素验证，避免只验证冷缓存。所有画面失败保留，不阻止可行性计时，但不能据此部署。独立存储和桌面、共享占用、内存预检及正式输入指纹沿父配方。运行后冻结。
